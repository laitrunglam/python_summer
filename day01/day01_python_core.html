Lý Thuyết Ôn Tập Chuyên Sâu: 4 Cấu Trúc Dữ Liệu & List Comprehension

📌 1. Phân Tích Kỹ Thuật 4 Cấu Trúc Dữ Liệu Cốt Lõi

Trong Python, việc lựa chọn đúng cấu trúc dữ liệu không chỉ giúp mã nguồn sạch mà còn quyết định trực tiếp hiệu năng thực thi của hệ thống khi xử lý mảng dữ liệu lớn.

List là chuỗi phần tử có thứ tự (ordered), hỗ trợ thay đổi (mutable) và cho phép lưu trữ các giá trị trùng lặp.

Cơ chế bộ nhớ CPython:

List trong CPython thực chất là một Mảng động các con trỏ (Array of Pointers). Khi bạn thêm phần tử bằng append(), Python sẽ cấp phát thừa bộ nhớ (Over-allocation) để đạt độ phức tạp O(1) amortized.

Độ phức tạp các thao tác phổ biến:

  • lst[i] (Truy xuất index): O(1) - Siêu tốc do tính toán địa chỉ ô nhớ trực tiếp.
  • lst.append(x) (Thêm cuối): O(1) amortized.
  • lst.insert(0, x) / lst.pop(0) (Chèn/Xóa đầu): O(n) - Tốn chi phí vì phải dịch chuyển toàn bộ phần tử phía sau.
  • x in lst (Tìm kiếm): O(n) - Duyệt tuyến tính từ đầu tới cuối mảng.

Dictionary là cấu trúc dữ liệu lưu trữ theo cặp Key-Value, tối ưu hóa cho việc tìm kiếm theo Key.

Quy tắc Hash Table & Key Immutability:

Key trong Dict bắt buộc phải là đối tượng Hashable (Immutable như int, str, tuple). Không thể dùng List hoặc Dict làm Key do chúng có thể bị thay đổi giá trị.

Độ phức tạp & Kỹ thuật truy xuất an toàn:

  • d[key] / d[key] = val: O(1) average nhờ hàm băm Hash Function.
  • Tránh crash KeyError: Sử dụng dict.get('key', default_value) thay vì truy xuất trực tiếp.
  • Duyệt nhanh: for key, val in d.items(): lấy đồng thời Key và Value.

Tuple là chuỗi phần tử cố định (Immutable). Sau khi được tạo ra, không thể thêm, sửa, xóa bất kỳ phần tử nào.

Tại sao nên dùng Tuple thay vì List?

  • Hiệu năng & Bộ nhớ: Tuple tốn ít dung lượng RAM hơn và khởi tạo nhanh hơn List.
  • Tính An Toàn Dữ Liệu: Đảm bảo dữ liệu cấu hình (ví dụ: tọa độ, DB credentials) không bị vô tình chỉnh sửa.
  • Dùng làm Key trong Dict: Do Tuple là Immutable (hashable) nên có thể làm Key cho Dictionary.

Set là tập hợp chứa các phần tử Duy nhất (Unique) và Không bảo toàn thứ tự.

Ứng dụng đại số tập hợp & Tìm kiếm siêu tốc:

  • x in set: O(1) - Nhanh gấp hàng ngàn lần so với x in list khi tập dữ liệu lớn.
  • Loại bỏ phần tử trùng lặp: unique_items = list(set(raw_list)).
  • Phép toán tập hợp: Hợp A | B, Giao A & B, Hiệu A - B.

⚡ 2. Hướng Dẫn List Comprehension Chi Tiết & Dễ Hiểu

List Comprehension là kỹ thuật tạo danh sách (List) ngắn gọn, mượt mà và tối ưu hiệu năng của Python. Giúp bạn thay thế toàn bộ vòng lặp for rườm rà 4-5 dòng thành chỉ 1 dòng duy nhất!

📌 Cấu trúc 3 thành phần cốt lõi:

new_list = [ [1. Expression] for item in iterable if [3. Condition] ]
  • 1. Expression (Giá trị đầu ra): Biểu thức tính toán hoặc biến bạn muốn đưa vào List mới (Ví dụ: x * 2, x.upper(), x["ten"]).
  • 2. For Loop (Vòng lặp): Duyệt qua từng phần tử item từ tập dữ liệu ban đầu iterable.
  • 3. Condition (Điều kiện lọc - Tùy chọn): Chỉ cho phép phần tử thỏa mãn điều kiện mới được thêm vào List mới.

🔄 So Sánh Trực Quan: Vòng Lặp For Thường vs List Comprehension

Cách 1: Vòng lặp For truyền thống (5 dòng) 
kq = []
for x in numbers:
    if x % 2 == 0:
        kq.append(x * 2)
Cách 2: List Comprehension (1 dòng siêu tốc) 
kq = [x * 2 for x in numbers if x % 2 == 0]

📊 3. Bảng So Sánh Tổng Hợp 4 Cấu Trúc Dữ Liệu

Cấu Trúc Cú Pháp Mẫu Thay Đổi (Mutable) Thứ Tự (Ordered) Trùng Lặp (Duplicates) Tra Cứu Phần Tử (Search)
List [1, 2, 3] ✅ Có ✅ Bảo toàn Index ✅ Cho phép O(n) linear search
Dictionary {"k": "v"} ✅ Có ✅ Thứ tự chèn (3.7+) ❌ Key duy nhất O(1) Hash search
Tuple (1, 2, 3) ❌ Không (Immutable) ✅ Bảo toàn Index ✅ Cho phép O(n) linear search
Set {1, 2, 3} ✅ Có ❌ Không thứ tự ❌ Không trùng lặp O(1) Hash search
