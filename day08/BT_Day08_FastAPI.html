Kết nối MySQL với Python bằng SQLAlchemy

Mục tiêu: cho phép code Python (backend) lưu và lấy dữ liệu sản phẩm từ một database MySQL được quản lý bằng MySQL Workbench, thông qua thư viện SQLAlchemy (ORM).

💡 Điểm mấu chốt: MySQL Workbench thao tác trực tiếp trên database vật lý bằng SQL thuần, còn Python + SQLAlchemy giao tiếp với database đó qua một lớp ánh xạ đối tượng (ORM) — không cần viết SQL tay.

Hình 1. MySQL Workbench tạo database, Python (SQLAlchemy) kết nối và thao tác dữ liệu qua driver pymysql.

4 file trong dự án và vai trò của chúng:

store_db.sql là tập lệnh DDL (Data Definition Language) — định nghĩa "hình dạng" của dữ liệu, chạy trực tiếp trong MySQL Workbench, độc lập với code Python.

Các lệnh chính:

LệnhÝ nghĩa
CREATE DATABASETạo "hộp chứa" riêng cho toàn bộ bảng của dự án, tránh đụng độ với database khác trên cùng MySQL Server
CREATE TABLEĐịnh nghĩa schema: tên cột, kiểu dữ liệu, ràng buộc (constraint)
INSERTLệnh DML (Data Manipulation Language) — chèn dữ liệu mẫu để test nhanh, không cần chạy Python

Vì sao chọn kiểu dữ liệu như vậy?

  • id INT AUTO_INCREMENT PRIMARY KEY: khóa chính tự tăng, đảm bảo mỗi dòng là duy nhất.
  • price DECIMAL(10,2) thay vì FLOAT/DOUBLE: tiền tệ cần chính xác tuyệt đối, không được sai số làm tròn của số thực dấu phẩy động.
  • updated_at ... ON UPDATE CURRENT_TIMESTAMP: MySQL tự động cập nhật thời gian mỗi khi dòng bị UPDATE — code Python không cần tự nhớ set giá trị này.
CREATE TABLE products (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    name         VARCHAR(255) NOT NULL,
    price        DECIMAL(10,2) NOT NULL DEFAULT 0,
    quantity     INT NOT NULL DEFAULT 0,
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
📌 File này chỉ cần chạy một lần (hoặc mỗi khi thay đổi cấu trúc bảng) — nó tách biệt hoàn toàn với vòng đời chạy của ứng dụng Python.

database.py là lớp kết nối, dựng nên 3 khái niệm cốt lõi của SQLAlchemy: Engine, Session, Base.

Hình 2. Ba thành phần cốt lõi được khai báo trong database.py.

Giải thích từng thành phần:

Thành phầnVai trò
create_engine(DATABASE_URL)Tạo kết nối tới MySQL; tái sử dụng connection thay vì mở/đóng liên tục (tốn tài nguyên)
mysql+pymysql://pymysql là driver — SQLAlchemy tự nó không giao tiếp mạng với MySQL được, cần driver trung gian
sessionmaker(bind=engine)Tạo "khuôn" để sinh ra các Session dùng chung 1 Engine

DATABASE_URL = f"mysql+pymysql://{user}:{password}@{host}:{port}/{db_name}" engine = create_engine(DATABASE_URL, pool_pre_ping=True) SessionLocal = sessionmaker(bind=engine) Base = declarative_base()

ORM (Object-Relational Mapping) là kỹ thuật ánh xạ giữa bảng SQL và class Python, để thao tác dữ liệu bằng object thay vì viết chuỗi SQL tay.

Bảng ánh xạ SQL ↔ SQLAlchemy:

SQL (store_db.sql)SQLAlchemy (models.py)
CREATE TABLE products__tablename__ = "products"
id INT PRIMARY KEYColumn(Integer, primary_key=True)
price DECIMAL(10,2)Column(Numeric(10,2))
name VARCHAR(255)Column(String(255))

Hình 3. ORM biến 1 dòng SQL thành 1 object Python có thuộc tính (attribute).

Lợi ích của ORM:

  • Thao tác bằng object Python (product.name) — IDE gợi ý, tránh lỗi cú pháp SQL.
  • Không phụ thuộc cụ thể vào MySQL — đổi sang PostgreSQL chỉ cần đổi DATABASE_URL, không cần sửa models.py.
  • Có thể thêm hàm tiện ích như to_dict() để phục vụ trả JSON cho API sau này.

demo.py minh họa 4 thao tác chuẩn CRUD (Create – Read – Update – Delete) thông qua Session.

Thao tácHàm SQLAlchemyTương đương SQL
Createdb.add(obj) → db.commit()INSERT INTO products ...
Readdb.query(Model).all() / .filter().first()SELECT * FROM products WHERE ...
Updatesửa thuộc tính object → db.commit()UPDATE products SET ... WHERE id=...
Deletedb.delete(obj) → db.commit()DELETE FROM products WHERE id=...

Hình 4. Vòng đời thao tác Create qua add → commit → refresh → close.

💡 Transaction & Rollback: nếu có lỗi giữa chừng, db.rollback() hủy toàn bộ thay đổi chưa commit, đảm bảo dữ liệu không bị lưu nửa vời (tính ACID). Luôn gọi db.close() trong finally để tránh rò rỉ connection.

Ví Dụ Code & Ngữ Cảnh Cụ Thể
📌 Ngữ Cảnh Bài Toán: Dự án Store Management — Lưu sản phẩm vào MySQL

Ở buổi trước, API GET /api/v1/store-info mới chỉ trả về mock data (dictionary viết cứng trong code). Bước tiếp theo là kết nối tới một database MySQL thật (tạo sẵn bằng MySQL Workbench) để lưu và lấy danh sách sản phẩm.
4 file bên dưới trích từ dự án thật: store_db.sql (chạy trong Workbench), app/database.py, app/models.py, app/demo.py — vì cần một MySQL Server thật đang chạy nên phần này chỉ hiển thị để đọc/tham khảo, không có nút chạy trực tiếp trên trình duyệt.

🗄️ store_db.sql
-- Chạy trong MySQL Workbench để khởi tạo database CREATE DATABASE IF NOT EXISTS store_db CHARACTER SET utf8mb4; USE store_db; CREATE TABLE IF NOT EXISTS products ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(255) NOT NULL, price DECIMAL(10,2) NOT NULL DEFAULT 0, quantity INT NOT NULL DEFAULT 0, created_at DATETIME DEFAULT CURRENT_TIMESTAMP ); -- Dữ liệu mẫu để test nhanh INSERT INTO products (name, price, quantity) VALUES ('Áo thun nam', 150000, 50), ('Giày sneaker', 550000, 20);
🔌 app/database.py
import os from sqlalchemy import create_engine from sqlalchemy.orm import sessionmaker, declarative_base # Thông tin kết nối tới MySQL Server đang chạy trong Workbench DB_USER = os.getenv("DB_USER", "root") DB_PASSWORD = os.getenv("DB_PASSWORD", "your_password") DB_HOST = os.getenv("DB_HOST", "127.0.0.1") DB_NAME = os.getenv("DB_NAME", "store_db") DATABASE_URL = f"mysql+pymysql://{DB_USER}:{DB_PASSWORD}@{DB_HOST}:3306/{DB_NAME}" # Engine: "cổng kết nối" tới MySQL, tự quản lý connection pool engine = create_engine(DATABASE_URL, pool_pre_ping=True) # Session: mọi thao tác add / query / commit đều đi qua đây SessionLocal = sessionmaker(bind=engine) # Base: lớp cha để ProductModel kế thừa Base = declarative_base()
📦 app/models.py
from sqlalchemy import Column, Integer, String, Numeric, DateTime from sqlalchemy.sql import func from app.database import Base class ProductModel(Base): __tablename__ = "products" id = Column(Integer, primary_key=True) name = Column(String(255), nullable=False) price = Column(Numeric(10, 2), nullable=False, default=0) quantity = Column(Integer, nullable=False, default=0) created_at = Column(DateTime, server_default=func.now()) def to_dict(self): return { "id": self.id, "name": self.name, "price": float(self.price), "quantity": self.quantity, }
🔁 app/demo.py
from app.database import engine, SessionLocal, Base from app.models import ProductModel def add_product(name, price, quantity): # Tạo Session mới cho mỗi thao tác db = SessionLocal() try: product = ProductModel(name=name, price=price, quantity=quantity) db.add(product) # đưa vào hàng đợi db.commit() # ghi thật xuống MySQL db.refresh(product) # lấy lại id do MySQL sinh ra print(f"✅ Đã thêm: {product.name} (id={product.id})") finally: db.close() def get_all_products(): db = SessionLocal() try: return db.query(ProductModel).all() finally: db.close() if __name__ == "__main__": Base.metadata.create_all(bind=engine) add_product("Quần jeans", 320000, 40) for p in get_all_products(): print(p.to_dict())
🚀 Cách chạy thử với dữ liệu thật

1. Mở MySQL Workbench, chạy store_db.sql để tạo database và bảng.
2. Cài thư viện: pip install sqlalchemy pymysql.
3. Sửa DB_PASSWORD trong database.py (hoặc set biến môi trường) cho đúng mật khẩu MySQL của bạn.
4. Chạy python -m app.demo — sản phẩm mới sẽ được thêm vào bảng products, sau đó danh sách được in ra dạng JSON. Có thể mở lại MySQL Workbench, chạy SELECT * FROM products; để xác nhận dữ liệu đã lưu.
