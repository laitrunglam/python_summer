Pydantic Schema & Router trong FastAPI

Pydantic là thư viện Python dùng để định nghĩa và kiểm tra kiểu dữ liệu (type-safe) thông qua các lớp kế thừa từ BaseModel. FastAPI dùng Pydantic làm "lớp hợp đồng dữ liệu" (data contract) giữa Client và Server.

💡 Điểm mấu chốt: Schema không lưu trữ dữ liệu — nó chỉ mô tả hình dạng (shape) dữ liệu hợp lệ. Việc lưu trữ thật sự là nhiệm vụ của Model (SQLAlchemy ORM).

Hình 1. Pydantic Schema đóng vai trò "cổng kiểm soát" dữ liệu trước khi chạm tới Model/Database.

3 nhóm Schema thường gặp trong một resource:

Schema Dùng khi Đặc điểm
ProductCreate Client gửi lên để tạo mới Không có id, các field bắt buộc theo nghiệp vụ
ProductUpdate Client gửi lên để cập nhật Thường tất cả field Optional
ProductResponse Server trả về cho Client Có thêm id, đọc được từ ORM object

Pydantic tự động validate dữ liệu đầu vào dựa trên kiểu dữ liệu (type hint) và các ràng buộc khai báo qua Field(). Nếu dữ liệu không hợp lệ, FastAPI tự trả về lỗi 422 trước khi code trong hàm xử lý (endpoint function) được chạy.

Schema ProductCreate cho resource "product":

from pydantic import BaseModel, Field

class ProductCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)
    price: float = Field(gt=0)
    stock: int = Field(ge=0)

Ý nghĩa từng ràng buộc:

Khai báo Ý nghĩa
min_length / max_length Giới hạn độ dài chuỗi
gt=0 Giá trị phải lớn hơn 0 (greater than)
ge=0 Giá trị phải lớn hơn hoặc bằng 0 (greater or equal)

Ví dụ request gây lỗi 422:

{
    "name": "",
    "price": -100,
    "stock": "abc"
}
// → 422 Unprocessable Entity: name rỗng, price âm, stock sai kiểu
📌 Validation xảy ra tự động, sinh viên không cần viết if/else kiểm tra thủ công cho những ràng buộc cơ bản như bắt buộc nhập, kiểu dữ liệu, khoảng giá trị.

Một lỗi phổ biến của người mới là dùng chung một lớp cho cả ORM Model và Schema. Cần tách biệt rõ vì hai lớp phục vụ hai mục đích khác nhau.

Product (SQLAlchemy Model) ProductCreate / ProductResponse (Pydantic Schema)
Vai trò Ánh xạ bảng trong database Định dạng dữ liệu trao đổi qua API
Kế thừa từ Base (declarative_base) BaseModel (Pydantic)
Có id? Luôn có, do DB tự sinh Chỉ có ở ProductResponse, không có ở ProductCreate
Nằm ở đâu models/product.py schemas/product.py

Cấu trúc Lớp Schema ProductResponse:

from pydantic import BaseModel

class ProductResponse(BaseModel):
    id: int
    name: str
    price: float
    stock: int

FastAPI sẽ tự động đọc dữ liệu và serialize đối tượng trả về thành JSON đúng cấu trúc khai báo trong ProductResponse.

APIRouter cho phép chia nhỏ các endpoint theo từng resource (products, users, orders...) thành các module riêng, rồi gộp lại tại main.py. Đây là ứng dụng trực tiếp của Layered/Modular Architecture đã học ở phần trước.

Hình 2. Mỗi resource có một Router riêng, được gộp lại vào app chính qua include_router().

Khai báo Router cho resource "product":

from fastapi import APIRouter

router = APIRouter(prefix="/products", tags=["Products"])
Tham số Ý nghĩa
prefix Tiền tố URL chung cho mọi endpoint trong router này (VD: /products)
tags Nhóm hiển thị trong Swagger UI (/docs) cho dễ nhìn

Hai endpoint nền tảng của resource "product", theo đúng chuẩn REST đã học: POST để tạo, GET để đọc.

Method Endpoint Schema Input Schema Output Status thành công
POST /products ProductCreate ProductResponse 201 Created
GET /products/{id} — (path param) ProductResponse 200 OK

Code hai endpoint:

@router.post("/", response_model=ProductResponse, status_code=201)
def create_product(product: ProductCreate, db: Session = Depends(get_db)):
    new_product = Product(**product.model_dump())
    db.add(new_product)
    db.commit()
    db.refresh(new_product)
    return new_product

@router.get("/{product_id}", response_model=ProductResponse)
def get_product(product_id: int, db: Session = Depends(get_db)):
    product = db.query(Product).filter(Product.id == product_id).first()
    if not product:
        raise HTTPException(status_code=404, detail="Không tìm thấy sản phẩm")
    return product

Vì sao cần response_model?

  • Đảm bảo dữ liệu trả về đúng "hợp đồng" — chỉ những field khai báo trong ProductResponse mới lộ ra ngoài (ẩn field nhạy cảm nếu có).
  • Tự sinh tài liệu API mẫu chính xác trong /docs (Swagger UI).
  • FastAPI tự động chuyển object ORM → JSON nhờ from_attributes = True.
💡 Depends(get_db) là cơ chế Dependency Injection của FastAPI — tự động mở một phiên kết nối database (Session) cho mỗi request và đóng lại khi request kết thúc.

Câu hỏi ôn tập (SV tự trả lời trước khi lên lớp):

  • Vì sao ProductCreate không có field id nhưng ProductResponse thì có?
  • Điều gì xảy ra nếu Client gửi price: -50 lên endpoint POST /products?
  • response_model giúp ích gì khi Model ORM có nhiều field hơn Schema cần trả về?
  • Vì sao nên tách Router theo từng resource thay vì viết hết endpoint trong main.py?
  • Tham số product_id trong GET /products/{id} được lấy từ đâu, khác gì với Body của POST?

Ví Dụ Code & Ngữ Cảnh Cụ Thể
📌 Ngữ Cảnh Bài Toán: Dự án Store Management — Tạo & Xem sản phẩm

Sau khi đã có GET /api/v1/health và GET /api/v1/store-info ở Buổi 5, bước tiếp theo là cho phép cửa hàng thêm sản phẩm mới và xem chi tiết một sản phẩm. Ta cần một Schema ProductCreate để kiểm tra dữ liệu Client gửi lên, và một Router riêng cho resource product với 2 endpoint: POST /api/v1/products và GET /api/v1/products/{id}.
Đoạn code bên dưới trích từ dự án thật store_management — vì đây là code FastAPI cần chạy bằng Uvicorn server và có kết nối database, nên phần này chỉ hiển thị để đọc/tham khảo, không có nút chạy trực tiếp trên trình duyệt.

🐍 app/schemas/product.py
from pydantic import BaseModel, Field class ProductCreate(BaseModel): # Dữ liệu Client gửi lên khi tạo sản phẩm mới name: str = Field(min_length=1, max_length=100) price: float = Field(gt=0) stock: int = Field(ge=0) class ProductResponse(BaseModel): # Dữ liệu server trả về cho Client, có thêm id id: int name: str price: float stock: int
🐍 app/api/v1/routers/product.py
from fastapi import APIRouter, Depends, HTTPException from sqlalchemy.orm import Session from app.core.database import get_db from app.models.product import Product from app.schemas.product import ProductCreate, ProductResponse router = APIRouter(prefix="/products", tags=["Products"]) @router.post("/", response_model=ProductResponse, status_code=201) def create_product(product: ProductCreate, db: Session = Depends(get_db)): # Tương ứng route POST /api/v1/products new_product = Product(**product.model_dump()) db.add(new_product) db.commit() db.refresh(new_product) return new_product @router.get("/{product_id}", response_model=ProductResponse) def get_product(product_id: int, db: Session = Depends(get_db)): # Tương ứng route GET /api/v1/products/{id} product = db.query(Product).filter(Product.id == product_id).first() if not product: raise HTTPException(status_code=404, detail="Không tìm thấy sản phẩm") return product
